## Dashboard Router Page
- Go to 192.168.1.1
- Enter username: admin
- Password: <start_with_ZTEG> below wifi modem

## Setting DNS IPv4
- Go to Local Network > LAN > IPv4
- Expand DHCP Server
- Turn off ISP DNS
- Enter Primary DNS: 8.8.8.8
- Enter Secodary DNS: 8.8.4.4
- Apply

## Setting DNS IPv6
- Go to Local Network > LAN > IPv4
- Expand DHCPv6 Server
- Choose DNS Delegate Type
- Enter DNS Server1: 2001:4860:4860::8888
- Enter DNS Server1: 2001:4860:4860::8844
- Apply
